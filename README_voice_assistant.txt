# المساعد الصوتي لذوي الاعاقة

برنامج بايثون يتيح فتح مواقع التواصل الاجتماعي بالاوامر الصوتية العربية.

## الملفات
- `voice_assistant_ar.py` : البرنامج الرئيسي
- `requirements.txt` : المكتبات المطلوبة

## التشغيل
1. ثبت المكتبات (تحتاج انترنت):
```
pip install -r requirements.txt
```
ملاحظة: مكتبة PyAudio على ويندوز قد تحتاج:
```
pip install pipwin
pipwin install pyaudio
```

2. شغل البرنامج بالواجهة:
```
python voice_assistant_ar.py
```

3. او بدون واجهة (سطر الاوامر):
```
python voice_assistant_ar.py --console
```

## الاوامر الصوتية
- افتح فيسبوك / افتح يوتيوب / افتح تويتر
- افتح انستغرام / افتح تيك توك / افتح واتساب
- افتح تيليغرام / افتح سناب شات / افتح جوجل / افتح جيميل
- مساعدة : لسماع الاوامر
- خروج : لاغلاق البرنامج

## ملاحظات لذوي الاعاقة
- ازرار كبيرة في الواجهة لمن يصعب عليه الكلام بوضوح.
- مربع كتابة بديل لمن لا يستطيع النطق.
- رد صوتي + نص مكتوب دائما (يناسب ضعاف السمع).
- التعرف الصوتي يحتاج مايكروفون + انترنت (خدمة جوجل).
